# 心动双人岛

不上架、只给两个人用的 Android 情侣应用。不是聊天软件的替代品，而是两部手机之间的共享情境：情绪数值、Buff、即时弹窗，以及电量、步数、距离这些设备状态。

登录页点「我是慧慧」或「我是江江」即可，不用填服务器地址和 Token。

> 仓库请保持 **Private**。客户端里写死了访问令牌和签名配置，公开后等于把两个人的入口交出去。

## 能做什么

- **状态**：自定义 0–100 的数值（想你值、心情等），滑动调节，可爆表；正面 / 负面 Buff；一句话弹到对方屏幕上
- **在场**：同步电量、是否充电、当日步数；双方都开定位时显示直线距离
- **触觉**：滑动数值时本机短振，和刻度对齐（设置里可关）
- **纪念日**：倒计时、置顶、当天提醒
- **留言**：文字 + 多图，按月筛选，看见才算已读
- **任务**：发给自己或对方，每日打卡、截止日期、拍照验收
- **出行 / 快递**：下次见面倒数、历史折叠；待取 / 已取；日程按天去重提醒
- **备份**：整库导出到系统「下载」，也可选 `.db` 恢复（会覆盖服务器当前数据）
- **桌面小组件**：恋爱天数、电量、步数、Buff、置顶纪念日

## 怎么实现的

```text
Android 客户端                    自建服务
Kotlin + Jetpack Compose    →    Go + SQLite
OkHttp / WebSocket               HTTP :9900
传感器 / 定位 / 振动器            图片 uploads/
Glance 小组件、WorkManager        整库备份 / 恢复
```

写入：本机操作或传感器读数 → HTTP 写入 SQLite → WebSocket 推给对方 → 界面刷新。

和手机的交互走系统服务，不自己估：

| 能力 | 系统接口 |
|------|----------|
| 电量 / 充电 | `BatteryManager`、电池状态广播 |
| 步数 | `SensorManager`（计步器，无则步进探测） |
| 位置 / 距离 | `LocationManager`（GPS + 网络），两边坐标齐全再算球面距离 |
| 滑条震感 | `Vibrator`，每格约 12ms |

强行停止应用后，系统不再给传感器和定位回调，在场信息会断，这是系统限制。

## 目录

```text
android/     客户端（包名 com.wh.island，minSdk 26，target 35）
server/      服务端（Go，监听 :9900）
island.jks   发布签名
```

## 跑服务端

需要 Go 1.22+（本仓库用过 1.27）。

```powershell
cd server
go run .
```

浏览器打开 `http://127.0.0.1:9900`，应看到 `心动双人岛 OK`。

数据在 `server/data/island.db`，上传图片在 `server/uploads/`。首次启动会写入两个用户；若库已存在则沿用现有令牌。

本机有 `server/tls/island.crt` 与 `island.key` 时，进程会尝试监听 `:443`。云主机上 443 若已被反向代理占用，把证书配到代理、反代到 `127.0.0.1:9900` 即可。公网 80 也可端口转发到 9900。

## 打 Android 包

需要 Android SDK。本机常用环境变量：

```powershell
$env:ANDROID_HOME = "D:\Android\Sdk"
$env:GRADLE_USER_HOME = "D:\g"
cd android
.\gradlew.bat assembleRelease
```

安装包输出：

`android/app/build/outputs/apk/release/app-release.apk`

覆盖安装到两部手机。第一部点慧慧，第二部点江江。

模拟器访问本机服务用 `http://10.0.2.2:9900`（当前正式包已写死公网地址，改地址需改 `LoginScreen.kt` 里的 `ISLAND_SERVER` 后重打包装）。

## 特点

封闭双人，没有注册和第三人。共享的是「现在怎样」，不是又一个会话列表。电量、步数、距离和滑条震感把手机当成传感与触觉通道。数据在自建库上，整库可导出、可回滚。

## 不在范围内

鸿蒙客户端、应用商店上架、开放注册、第三方对象存储、强停之后仍 24 小时上报定位。
